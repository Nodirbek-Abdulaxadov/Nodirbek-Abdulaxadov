## 👨‍💻 About

.NET engineer based in Uzbekistan, focused on backend, clean architecture, and understanding what code does under the hood — memory, allocations, concurrency — not just that it runs. I like designing systems and turning ideas into working products.

- 📦 Author of **NuGet** libraries, written from scratch
- 🏗️ Designed and shaped **Musanna** — a multi-tenant SaaS ecosystem
- 🦀 Exploring language design with **JWC**, a hobby project in Rust
- 🎓 Applied Mathematics & Informatics — analytical approach to engineering
- 👨‍🏫 Mentored developers at RTM Margilan & Najot Ta'lim
